# Changelog

## 2.0.1

- Sorting mods such as ClientSort leave crate stacks, upgrades and locks alone
- Requires Assorted Lib 5.0.2

## 2.0.0

Updated to Minecraft 26.3, for NeoForge and Fabric.

- Added Poplar storage crates
- Requires Assorted Lib 5.0.0

## 1.0.0

- First release as its own mod. It used to only be part of Assorted Storage
- Worlds from Assorted Storage 11.x keep all of their crates, controllers, bridges and upgrades along with what is in them
- Level upgrades still fit in crates when Assorted Level Upgrades is installed too
- Requires Assorted Lib 4.3.0

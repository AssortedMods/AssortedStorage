# Assorted Crates

Adds storage crates in every wood that hold a lot of one kind of item. Double, triple and quadruple crates split that room between more items. A crate controller joins a whole wall of crates into one inventory and a crate bridge carries the network across a gap. The compacting crate shows an item as its block and its nuggets too. Crate upgrades add glow, void, amount and redstone, and the rotator majig turns a block to face the way you want.

Also included in [Assorted Storage](../storage). Worlds made with Assorted Storage 11.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).

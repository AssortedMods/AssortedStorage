# Changelog

## 21.1.0.0

First release for Minecraft 1.21.1, for NeoForge and Fabric. Releases for 1.21.1 are numbered 21.1.x.y, where 21.1 is the Minecraft version.

- Matches Assorted Storage 13.0.2 for Minecraft 26.3
- Includes Assorted Chests, Assorted Barrels, Assorted Shulkers, Assorted Hoppers, Assorted Crates, Assorted Bags, Assorted Containers, Assorted Locks and Assorted Level Upgrades, each at 21.1.0.0
- Requires Assorted Lib 21.1.0.0

# Assorted Storage

Assorted blocks and items useful for storage. This includes Assorted Chests, Assorted Barrels, Assorted Shulkers, Assorted Hoppers, Assorted Crates, Assorted Bags, Assorted Containers, Assorted Locks and Assorted Level Upgrades in one download.

If you only want some of them you can install those mods on their own instead. Your world keeps everything either way.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
